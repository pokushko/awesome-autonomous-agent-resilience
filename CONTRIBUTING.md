# Contributing to Awesome Autonomous Agent Resilience

We welcome high-quality contributions from the community!

## Guidelines
1. **Focus on Resilience:** Submissions must directly address fault-tolerance, memory boundedness, chaos testing, security isolation, or deterministic recovery of autonomous AI agents.
2. **Quality over Quantity:** Prefer production-verified tools, reproducible benchmarks, and peer-reviewed/arXiv papers.
3. **Format:** Use the standard markdown format:
   `- [Project Name](URL) - Concise one-line description of why it improves agent resilience.`
4. **Alphabetical Ordering:** Keep entries organized logically within each section.
